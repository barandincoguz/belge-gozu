# Issue tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues. Use the `gh` CLI from
the repository root; infer `barandincoguz/belge-gozu` from the configured remote.

- Create: `gh issue create --title "..." --body "..."`
- Read: `gh issue view <number> --comments`
- List: `gh issue list --state open --json number,title,body,labels,comments`
- Comment: `gh issue comment <number> --body "..."`
- Labels: `gh issue edit <number> --add-label "..."`
- Close: `gh issue close <number> --comment "..."`

Any comment or issue body created during triage must begin with:

```text
> *This was generated by AI during triage.*
```
