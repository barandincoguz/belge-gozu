# Triage labels

The canonical triage roles map directly to these GitHub label names:

| Role | Label | Meaning |
| --- | --- | --- |
| needs-triage | `needs-triage` | Maintainer needs to evaluate |
| needs-info | `needs-info` | Waiting on reporter information |
| ready-for-agent | `ready-for-agent` | Fully specified and AFK-ready |
| ready-for-human | `ready-for-human` | Requires human implementation or decision |
| wontfix | `wontfix` | Will not be actioned |
